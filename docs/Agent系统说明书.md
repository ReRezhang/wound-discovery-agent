# 慢性难愈创面文献发现型Agent：系统说明书

> GOAI世界人工智能开源大赛 · 前沿探索赛道（开放探索赛题）
> 版本：v1.0（初赛）｜日期：2026-08
> 声明：本系统仅用于科学研究，不构成任何临床诊疗建议；全部数据来自公开文献。

---

## 1. 系统概述

本系统是一个**文献驱动的科学发现Agent**，面向"慢性难愈创面×智能敷料"这一具体科学问题，实现从海量文献中自动识别研究空白（Research Gap）、生成可验证研究假设、并对自身产出进行引用真实性核验的完整闭环。

设计哲学：**LLM只负责内容生成，一切与"真实性"相关的环节由确定性程序执行。** 这一架构选择直接回应赛题的四条硬约束（证据链、新知已知分清、拒绝黑箱、零虚假引用）。

## 2. 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                     发现管线（8环节）                      │
├─────────────────────────────────────────────────────────┤
│ ① 文献检索    PubMed E-utilities API（主检索+定向补充）    │
│      ↓                                                  │
│ ② 全文解析    PMC开放全文XML → 结构化JSON（标题/摘要/分节） │
│      ↓                                                  │
│ ③ 实体抽取    LLM + 创面领域9字段schema（每字段附原文证据句）│
│      ↓                                                  │
│ ④ Gap扫描     LLM对语料库地图做系统性空白识别              │
│      ↓  【PMID白名单校验：程序拦截编造引用】               │
│ ⑤ 新颖性查重  每条Gap自动生成PubMed检索式，全库回查         │
│      ↓  【程序计数 + LLM逐条判读相关性，全程留日志】        │
│ ⑥ 假设生成    LLM基于"证据包"生成可验证假设+实验设计        │
│      ↓                                                  │
│ ⑦ 证据核验    引句逐字回原文比对（归一化匹配+滑动窗口兜底）   │
│      ↓  【无法验证的引用环自动剔除】                      │
│ ⑧ 报告生成    程序组装调研报告（数据全部来自已核验文件）     │
└─────────────────────────────────────────────────────────┘
```

## 3. 核心增量（相对开源组件的自有贡献）

| # | 增量 | 解决的问题 |
|---|------|-----------|
| 1 | **创面领域抽取schema**（材料基体/交联结构/负载物/响应机制/创面模型/病原菌/结局指标/证据等级/创新点，每字段强制附原文证据句） | 通用抽取无法覆盖创面修复领域的专业实体关系 |
| 2 | **PMID白名单校验器** | LLM生成Gap时引用的PMID必须存在于语料库，程序自动核查、无效整条打回——LLM"编文献"在机制上不可能通过 |
| 3 | **证据句逐字核验器** | 假设的每一环证据quote，归一化后与原文全文比对（含滑动窗口相似度兜底），通不过自动剔除并记录 |
| 4 | **全库新颖性查重模块** | 每条Gap自动生成PubMed检索式全库回查，程序客观计数+LLM逐条判读相关性，输出A/B/C三档判定，检索式与判读理由全部留档可复核 |
| 5 | **PMID程序挂载机制** | 文献标识符由程序从API元数据挂载，绝不经过LLM——从数据流根上杜绝虚假引用 |

## 5. 数据与日志（可复核性设计）

每个环节产出独立落盘文件，构成完整的"探索日志"：

| 文件 | 内容 | 对应的评审约束 |
|------|------|---------------|
| `*_metadata.csv` | 检索元数据（PMID/DOI/标题/期刊） | 证据链 |
| `*_fulltext.jsonl` | 结构化全文（分节正文） | 证据链 |
| `*_extracted.jsonl` | 实体抽取结果（逐字段附证据句） | 证据链 |
| `*_gaps.json` | Gap清单（PMID白名单校验通过） | 新知已知分清 |
| `*_novelty_log.json` | 查重日志（检索式/命中数/逐条判读/判定） | 零虚假引用、可复核 |
| `*_hypotheses.json` | 假设+证据链（核验净化后的净版） | 拒绝黑箱 |

评委可对任意一条结论执行三层复核：PMID是否真实（API可查）→ 引句是否在原文中（逐字匹配）→ 查重检索式是否支持"未见报道"判定（日志可重放）。

## 6. 已知局限（诚实声明）

1. 语料库限于PMC开放获取全文，订阅制期刊未覆盖，"未见报道"的准确含义是"基于PubMed公开索引及PMC开放全文检索未见报道"；
2. 查重相关性的最终判读由LLM基于标题完成，边界情形（B档）需人工复核；
3. 假设中的量化指标为假设性预期目标，非既有结论（报告中已逐处标注）；
4. 专家审核为必需环节：系统的定位是"为领域专家生产候选发现"，不是替代专家判断。

## 7. 复赛路线图

- 语料库扩至200-300篇，接入更多开放全文源（Europe PMC OA子集、bioRxiv）；
- Gap生成升级为多轮迭代闭环：查重反馈反哺提示词，被淘汰的假设进入"否定记忆"防止重复生成；
- 建设由创面专科医生标注的金标准评测集，输出抽取准确率/召回率等定量指标；
- 增加claim-证据对齐校验（判断引句是否真正支撑论点，而不仅是逐字存在）；
- 代码收编为可复现仓库（脚本化+一键运行+notebook演示）。
