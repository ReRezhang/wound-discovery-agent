## 摘要（约400字）

慢性难愈创面（糖尿病足溃疡、静脉性溃疡、压疮）愈合停滞与微环境异常（高ROS、蛋白酶失衡、生物膜感染、巨噬细胞极化障碍）密切相关，智能响应型敷料是重要干预方向，但"材料体系×响应机制×生物活性负载"的组合空间巨大且分散于海量文献中，人工调研难以穷尽。本项目构建文献驱动的科学发现智能体：以9字段领域schema自动抽取77篇开放全文的"材料—机制—性能"知识，系统性扫描研究空白（Gap），经全库新颖性查重判定后生成可验证假设，并以"PMID程序挂载、白名单校验、证据逐字核验"三道程序性防线保证引用零虚假。阶段性成果：识别12条候选Gap（6条经全库查重未见报道），产出3条证据链完备的可验证假设（MMP-9响应双酶解构生物膜、MMP-9/NE双酶"AND门控"响应、ROS响应NAC+GSNO级联共递送）。本项目为慢性创面敷料的理性设计提供了可复用的智能发现范式，全部代码、数据与探索日志开源可复核。

**关键词**：慢性难愈创面；智能响应敷料；科学发现智能体；文献挖掘；证据链核验

## （一）立项依据与研究内容

### 1. 项目的立项依据

**1.1 临床需求与科学意义**

慢性难愈创面是糖尿病、血管疾病及老龄化社会的重要并发症。以糖尿病足溃疡为例，其愈合停滞与创面微环境的病理性改变——持续性高活性氧（ROS）、基质金属蛋白酶（MMPs）与中性粒细胞弹性蛋白酶（NE）失衡、细菌生物膜形成、巨噬细胞M1/M2极化障碍——密切相关[1,2]。传统敷料仅提供被动覆盖与吸收功能，难以干预上述病理环节。

**1.2 国内外研究现状与发展动态**

智能响应型敷料能感知创面微环境（pH、ROS、酶、葡萄糖、光、温度）并按需释放治疗物质，已成为创面修复研究的前沿方向。本项目对2019年以来77篇开放获取全文的系统化分析显示：响应机制涵盖pH响应（如氧化透明质酸体系[3]）、ROS响应（如海藻酸盐/依达拉奉体系[4]）、酶响应（如MMP-2/9响应糖肽水凝胶[1]、pH/酶双响应GelMA体系[5]）、光响应供氧体系[6-8]及多重响应复合体系[9]；负载物涵盖抗菌肽[1]、外泌体[10,11]、生长因子[12]、免疫代谢调节剂[13]等。

**然而**，对文献交叉引用矩阵（材料×响应机制×负载物×病原体，详见附录A）的系统性扫描表明，上述组合空间远未被穷尽：多数工作仅探索单一响应机制递送单一负载物，跨机制组合、多模态协同、针对生物膜基质本身的响应性干预等方向存在结构性空白。

**1.3 问题的提出：组合空间探索需要新范式**

智能敷料的"材料×机制×负载"组合空间随文献增长呈组合爆炸，人工文献调研无法系统覆盖。近年"AI for Science"范式兴起，大语言模型（LLM）为文献知识的自动抽取与假设生成提供了可能；但LLM直接应用于科学发现存在致命缺陷——**幻觉与虚假引用**，这在科学场景下不可接受。因此，核心挑战在于：如何让LLM驱动的发现过程**全程可溯源、可验证、可复核**。

**1.4 本项目思路**

本项目构建文献驱动的科学发现智能体，其设计哲学为"**LLM只负责内容生成，一切与真实性相关的环节由确定性程序执行**"：文献标识符由程序挂载、Gap引用经白名单校验、新颖性由全库检索式客观判定、证据引句逐字回原文核验。初赛阶段已跑通完整管线并取得阶段性发现（见研究基础）。

### 2. 项目的研究内容、研究目标，以及拟解决的关键科学问题

**2.1 研究目标**

构建并开源一个面向慢性难愈创面智能敷料的文献驱动科学发现智能体，实现"海量文献→结构化知识→研究空白→可验证假设"的全自动、可溯源发现闭环；产出不少于5条经核验的可验证假设，并对综合评分最高者完成材料学初步验证。

**2.2 研究内容**

- **内容一：创面领域文献知识的可信自动抽取。** 建立9字段领域schema（材料基体/交联结构/负载物/响应机制/创面模型/病原菌/结局指标/证据等级/创新点），逐字段强制附原文证据句；构建"材料—机制—性能"知识图谱与交叉引用矩阵。
- **内容二：研究空白的系统识别与新颖性客观判定。** 基于语料地图的Gap系统扫描（PMID白名单校验）；每条Gap自动生成PubMed查重检索式全库回查，程序客观计数＋LLM逐条判读相关性，输出A（未见报道）/B（沾边未覆盖）/C（已有人做）三档判定，全程留档可复核。
- **内容三：假设生成、证据核验与初步验证。** 基于证据包生成可验证假设（含实验设计）；证据链引句逐字回原文核验，无法验证者自动剔除；对最优假设开展水凝胶成胶性与响应性降解的初步材料学验证。

**2.3 拟解决的关键科学问题**

1. **文献科学知识的可信机器抽取问题**：如何约束LLM仅基于原文生成结构化知识，并使其每一条产出都可回溯源文？（对应幻觉抑制与证据链问题）
2. **组合空间中科学假设的新颖性判定问题**：如何区分"真空白"与"检索不足造成的假空白"，使发现的新颖性判定可量化、可复核？（对应新知与已知分清问题）

### 3. 拟采取的研究方案及可行性分析

**3.1 技术路线**

```
文献检索(PubMed API) → 全文结构化解析(PMC XML) → LLM实体抽取(9字段schema+证据句)
      → Gap系统扫描【PMID白名单校验】→ 全库新颖性查重【检索式留档+三档判定】
      → 假设生成【证据包约束】→ 证据链逐字核验【未通过自动剔除】
      → 报告自动生成 → (复赛)多轮迭代搜索闭环 → 材料学初步验证
```

**3.2 研究方法要点**

- 文献获取：PubMed E-utilities主检索（"chronic wound"×智能敷料×促愈合机制，2019–2026）＋定向补充检索（硝化应激、邻苯二酚类抗氧化剂等）；
- 知识抽取：LLM（qwen-plus）零温度抽取，证据句逐字约束；
- 新颖性判定：查重检索式自动生成，命中计数由程序完成，相关性判读留档；
- 证据核验：归一化子串匹配＋滑动窗口相似度（阈值0.85）双保险；
- 金标准评测（复赛）：由创面方向主任医师对30篇文献人工标注，计算抽取准确率/召回率；
- 材料验证（复赛）：水凝胶成胶性、流变学、酶/ROS响应降解曲线。

**3.3 可行性分析**

- 数据可行：PubMed/PMC提供稳定免费API，开放全文足以支撑发现管线（初赛77篇已验证）；
- 技术可行：管线全部环节已在初赛端到端跑通，产出12条Gap与3条核验假设；
- 团队可行：临床医学（负责人）＋水凝胶材料学（成员A）＋创面临床权威（成员B）三角配置，覆盖"临床问题—材料实现—临床验证"全链条；
- 风险与对策：扩库后Gap新颖性可能下降（如实呈现A/B/C分布，证伪本身即系统价值）；LLM幻觉（三道程序防线，复赛再加claim-证据对齐校验）。

### 4. 本项目的特色与创新之处

1. **"LLM生成＋程序保真"的发现架构**：PMID程序挂载、白名单校验、证据逐字核验三道确定性防线，使虚假引用在机制上不可能通过——区别于一般LLM文献工具；
2. **新颖性判定的客观化**：以"全库检索式＋程序计数＋判读留档"替代"LLM自评新颖"，查重系统可同时证实与证伪（初赛5条Gap被系统自身判C级淘汰）；
3. **"文献→假设→实物"的闭环尝试**：依托团队材料学能力，将Agent产出假设推进至水凝胶初步制备与响应性验证，在同类文献驱动研究中少见。
