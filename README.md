# wound-discovery-agent

慢性难愈创面智能敷料的文献驱动科学发现Agent
GOAI世界人工智能开源大赛 · 前沿探索赛道｜队伍：循迹·愈研（HealTrail）

## 这是什么
从PubMed开放文献中自动识别创面敷料领域的研究空白（Gap），经全库新颖性查重后生成可验证假设，全过程证据链可溯源、引用经程序核验。

## 一键复现
在Google Colab打开 notebook/wound_agent.ipynb，按格子顺序运行。
（需在Colab左侧🔑Secrets中配置自己的 BAILIAN_API_KEY；检索代码中的邮箱替换为自己的）

## 交付物
- docs/调研报告_v5.md —— 文献调研报告（Gap清单、查重记录、3条假设）
- docs/立项申请书.md —— 国自然风格版报告

- docs/Proposal.md —— 复赛计划
- data/ —— 全部探索日志（可复核）

## 声明
仅用于科学研究，不构成任何临床诊疗建议；全部数据来自PubMed/PMC公开文献。
